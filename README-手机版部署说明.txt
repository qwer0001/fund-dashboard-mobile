基金看板 · 手机版 PWA v1.0.0

一、这是什么
这是“可安装网页 App（PWA）”，不是传统 APK。
部署到 HTTPS 地址后：
- Android：Chrome/Edge 打开网址 → 添加到主屏幕/安装应用
- iPhone：Safari 打开网址 → 分享 → 添加到主屏幕
安装后会有独立图标、独立窗口，使用感接近普通 App。

二、公共云端
已配置为与电脑 v4.0.0 相同的 Supabase 项目。
手机和电脑登录同一个基金看板账号后，读写同一份：
- 当前最新主线
- 最近 10 次历史版本

网页源码中只包含 Supabase Project URL 和 Publishable key。
没有包含：登录密码、数据库密码、service_role/secret key。

三、v1.0.0 已支持
- Supabase 邮箱/密码登录
- 读取电脑已经建立的公共云端主线
- 查看基金持仓、成本、收益
- 刷新基金正式净值与盘中参考估值
- 添加基金
- 修改份额/成本/名称/类型
- 删除基金
- 记录买入、卖出、清仓为待确认操作
- 正式净值出现后确认待确认操作，并自动生成新主线
- 最近 10 次历史版本
- 选择旧历史“设为最新主线”
- revision 冲突保护：电脑/另一台手机先更新后，旧手机不能覆盖新云端
- 导出当前云端主线 JSON
- 本机缓存上次主线和净值，临时断网仍能查看缓存

四、注意
1. 不能直接双击 index.html 当正式手机版使用。PWA 和 Service Worker 需要 HTTPS 网站地址。
2. 下一步把整个文件夹部署到一个 HTTPS 静态网站即可。文件不需要 npm、不需要编译。
3. 推荐先用 GitHub Pages / Cloudflare Pages / Vercel 任一静态托管方式。
4. 如果以后确实需要 Android APK，可以在这套 PWA 上再封装，不需要重写基金账本逻辑。
