基金看板 手机版 PWA v2.3.6 可信设备登录版

这版修复的问题：
- 旧版本的登录令牌不会再被当成新版已授权登录。
- 升级到 v2.3.6 后，第一次必须手动输入密码并点击“安全登录”一次。
- 仅点击邮箱/密码输入框、浏览器自动填充、弹出键盘，都不会触发进入看板。
- 第一次在 v2.3.6 登录成功后，这台手机会被标记为可信设备。以后正常关闭、刷新、重新打开都可以自动登录。
- 主动点击“退出登录”后，会取消这台手机的免登录授权，下次需要重新输入密码。
- 历史记录继续保留最新30条，超过3天仍保留，直到被第31条新记录挤掉。

GitHub 更新：
1. 覆盖上传 index.html、app.js、styles.css、sw.js、manifest.webmanifest、icons 文件夹。
2. Commit changes。
3. 等 GitHub Pages 部署完成后，完全关闭手机上的旧PWA/浏览器页面再重新打开。
4. 第一次看到登录页时，先不要点登录：只点击密码框测试，页面必须保持在登录页。
5. 输入正确密码并点击“安全登录”后进入；以后再打开可自动进入。

Supabase：无需重新运行历史30条SQL。
