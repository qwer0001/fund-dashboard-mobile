基金看板 手机版 PWA v2.3.5 一次重新登录后长期保持版

你要的登录规则：
1. 从旧版本升级到 v2.3.5 后，第一次打开会强制清除旧版本遗留的登录状态。
2. 第一次必须重新输入邮箱和密码登录一次。
3. 这次登录成功以后，同一台手机会保存有效会话，后续关闭、重新打开或刷新都可以自动登录，不需要反复输入密码。
4. 只有主动点击“退出登录”、会话失效、清除站点数据或换设备时，才需要重新登录。
5. 没有有效登录会话时，基金持仓、收益、历史和操作页面全部隐藏，也不能调用云端写入。
6. 历史规则不变：最多保留30条；超过3天仍保留，只有第31条出现时才淘汰最老记录。

GitHub 更新方法：
- 将本文件夹里的 index.html / app.js / styles.css / sw.js / manifest.webmanifest / icons 覆盖上传到现有 GitHub Pages 仓库根目录。
- Commit changes。
- 等 GitHub Pages 部署完成。
- 第一次打开新版时应看到登录页；登录一次后，再关闭重开，应能自动进入。

测试方法：
A. 首次打开新版：必须看到登录页。
B. 登录成功：可正常读取/写入私有云。
C. 关闭网页/PWA再打开：应自动进入，不再要求密码。
D. 点“退出登录”后再打开：必须重新登录。
