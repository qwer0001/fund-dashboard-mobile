基金看板 手机版 PWA v2.3.7 个人交易体验优化版

本版新增：
- 已有基金可直接从动态下拉框选择，不再每次输入基金代码。
- 下拉列表直接读取当前 Supabase 主线账本；以后新增基金成功进入账本后会自动出现在列表中。
- 新基金仍保留“＋ 新基金 → 输入6位代码 → 自动识别”的入口。
- 全部卖出无需填写金额，会显示当前持有金额并进行二次确认。
- 普通卖出若超过当前可识别持有金额，会阻止提交并提示。
- 交易仍先写入待确认操作，正式净值公布后再更新份额/成本。

保留不变：
- Supabase 单一最新主线、revision / expected_revision 冲突保护。
- Supabase 最新30条历史；行情刷新不会制造历史版本。
- v2.3.6 的可信设备登录机制继续沿用，本次升级不会要求已授权手机重新手动登录。
- 主动退出后仍会取消可信设备授权。
- RLS、安全模型、数据库表结构、RPC 与电脑端同步协议均未改变。

GitHub Pages 更新：
1. 覆盖上传 index.html、app.js、styles.css、sw.js、manifest.webmanifest、README-部署说明.txt、icons 文件夹。
2. Commit changes。
3. 等 GitHub Pages 部署完成。
4. 完全关闭旧 PWA/浏览器页面再重新打开；如仍看到旧界面，再关闭一次或清理站点缓存后重开。

Supabase：本版无需更新数据库、无需重新运行 SQL。
