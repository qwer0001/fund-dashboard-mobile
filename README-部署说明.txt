基金看板手机版 v2.3.2（手机优先适配版）

本版在 v2.3.1 基础上只优化手机 UI / 响应式布局，不改变 Supabase 地址、账号登录、持仓计算、行情接口与历史规则。

历史规则：
- 最多保留最近30条历史记录。
- 不按3天到期删除。
- 即使记录超过3天，只要总数没有超过30条，仍继续保留。
- 新增第31条时，才淘汰最老的一条。

手机UI改进：
- 首页改为手机优先布局。
- 当前持有额作为主卡片，今日预估/正式收益并排。
- 大盘固定2列显示，避免小屏拥挤。
- 估值明细改为手机网格，不再强制横向拖动。
- 基金卡片信息重新分组，金额与关键收益更醒目。
- 360/390/430px 等常见手机宽度分别适配。
- 输入框改为16px，减少部分手机浏览器自动放大。
- 底部导航继续保留：首页 / 操作 / 历史 / 设置。
- 设置页、历史页、走势图弹层针对手机重新排版。
- Service Worker 缓存版本已升级，覆盖 GitHub 文件后会自动淘汰旧缓存。

更新 GitHub：
1. 解压本 ZIP。
2. 把 index.html、app.js、styles.css、sw.js、manifest.webmanifest、icons 文件夹覆盖上传到原 GitHub Pages 仓库。
3. Commit changes。
4. 等 GitHub Pages 发布完成后，手机完全关闭旧页面再重新打开。
5. 如果仍看到旧样式，可从手机桌面删除旧 PWA 后，用同一个 GitHub Pages 地址重新“添加到主屏幕”。
